# java-lms
# This repository will serve as a version control for the final project in CCS0023L.
<h3>Package Responsibilities</h3>

lms.model — Data models, encapsulation, inheritance, and enums. <br>
lms.dao — Database queries and CRUD operations. <br>
lms.service — Business rules, validation, and borrowing/return transactions. <br>
lms.database — Database connection configuration. <br>
lms.exception — Custom application exceptions. <br>
lms.gui — Java Swing interface and event handling. 

<h3>Project Status: </h3>

The initial classes and packages are placeholders. Their existence does not mean their functionality has been implemented.
Implementation responsibilities and task assignments should be agreed upon before development begins.
